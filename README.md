## 🚀 Flujos del Sistema

1. **Registro y Onboarding**: Proceso guiado para dar de alta un edificio en minutos.
2. **Control Financiero**: Gestión de cuotas ordinarias/extraordinarias y control de morosidad.
3. **Transparencia**: Visualización en tiempo real de fondos y egresos para todos los residentes.
4. **Documentación**: Gestor centralizado de reglamentos, actas y facturas.

## 🛠️ Stack Tecnológico

- **Frontend**: Vanilla ES6+, HTML5, CSS3 (Modular).
- **Backend**: Node.js, Express (Worker Ready).
- **Base de Datos**: Cloudflare D1 (SQLite).
- **Archivos**: Cloudflare R2.
